架构特性与部署边界解密

关于 GitHub Pages 网页版与真实 Windows 本地客户端的核心差异说明

🌐

长期在线访问性

托管于 GitHub Pages 官方高可用 CDN。只要 GitHub 仓库存在，此网址享有永久 HTTPS 访问、全球无缝加速与 99.99% 在线 SLA，无服务器维护费用。

🛡️

浏览器沙箱硬限制

网页端属于纯前端演练 Demo。受浏览器 安全沙箱 (Web Sandbox) 限制，网页无法跨出浏览器去监控全系统的底层按键（如全局双击 Alt），亦无法跨进程读取其他桌面软件的选区。

💻

本地原生全功能体验

若需真正的 Windows 全局划词即时调度（支持在任意 IDE、微信、浏览器中划词双击 Alt 就地替换），请下载 GitHub 仓库代码直接运行本地守护进程。
